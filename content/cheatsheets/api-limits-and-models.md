### Токенайзер: почему тот же текст стал дороже

**Модели 4.7 и новее** (Opus 4.7/4.8, Opus 5, Fable 5/5.1, Mythos) используют новый
токенайзер — он даёт примерно **на 30% больше токенов на том же тексте**. Sonnet 4.6 и всё,
что старше, — на прежнем токенайзере.

Практический вывод: при переезде с Sonnet 4.6 на Opus 5 пересчитай бюджет заново.
Цена за токен и число токенов изменились одновременно, и оценка «по старой памяти» промахнётся.

### Prompt Caching — множители к базовой цене input

| Операция | Множитель | Живёт |
|---|---|---|
| Запись в кэш на 5 минут | 1.25× | 5 минут |
| Запись в кэш на 1 час | 2× | 1 час |
| Чтение из кэша (hit) | 0.1× | пока жива запись |

Кэш-хит стоит 10% обычного input — то есть 5-минутный кэш окупается **с первого** чтения,
часовой — со **второго**. На Fable 5.1 и Mythos 5.1 хит стоит 0.025× ($0.25 за 1M) — там
кэш выгоднее в разы.

### Batch API

Скидка **50% на вход и выход**, ответ в течение 24 часов. Складывается с кэшированием.
Не работает вместе с Fast Mode.

### Fast Mode

Research preview, только **Opus 5 и Opus 4.8**, только первый API Anthropic (не Bedrock/Vertex/Foundry).
Тариф — $10 / $50 за 1M, то есть вдвое дороже обычного Opus. На Opus 4.7 `speed: "fast"`
возвращает ошибку.

### Резидентность данных

`inference_geo: "us"` на моделях 4.6+ даёт множитель **1.1×** ко всем категориям токенов.
Значение по умолчанию `global` — без наценки.

### Коды ошибок

| Код | Название | Что делать |
|---|---|---|
| 400 | Invalid Request | Не ретраить — чинить схему запроса |
| 401 | Authentication Error | Проверить API-ключ или профиль `ant auth` |
| 403 | Permission Error | Ключ есть, но нет прав на ресурс/воркспейс |
| 404 | Not Found | Проверить id модели: он без датского суффикса |
| 413 | Request Too Large | Резать вход, выносить документы в Files API |
| 429 | Rate Limit Exceeded | Retry с экспоненциальным backoff |
| 500 | API Error | Ретраить, это сторона Anthropic |
| 529 | Overloaded | Повторить через 2–5 секунд |

### Не ошибка, но обрыв: `stop_reason: "refusal"`

Приходит с **HTTP 200**. Код, который сразу читает `content`, не сверившись со `stop_reason`,
тихо получит пустоту вместо ответа. Всегда проверяй `stop_reason` до чтения контента —
подробности в статье про отказы и fallback.

Тарифы Fast Mode и пороги минимального объёма для кэширования меняются чаще прочего —
перед публикацией в проде сверяй с platform.claude.com/docs/en/about-claude/pricing.
