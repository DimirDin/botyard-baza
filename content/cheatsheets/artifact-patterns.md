### Когда артефакт уместен

Когда терминальный текст — неподходящий носитель: на вывод удобнее смотреть и с ним
удобнее повзаимодействовать, чем читать построчно.

### Паттерны

**Провести по изменению**
```text
Сделай артефакт, проводящий по этому PR. Отрисуй диф с аннотациями на полях
и раскрась находки по серьёзности.
```

**Сравнить варианты**
```text
Сделай артефакт с четырьмя заметно разными лейаутами панели настроек.
Варьируй плотность и группировку, разложи сеткой, под каждым — строчка с компромиссом.
```

**Подобрать значения интерактивно**
```text
Собери артефакт со слайдерами для кривой easing, длительности и задержки.
Показывай анимацию вживую.
```

**Вернуть результат в сессию**
```text
Сделай доску триажа: задачи карточками по колонкам Now, Next, Later, Cut.
Добавь кнопку «Copy as prompt» с итоговым порядком для вставки обратно сюда.
```

**Следить за длинной задачей**
```text
Преврати план миграции в артефакт-чек-лист. Отмечай пункты по мере выполнения
и добавляй заметку про всё, что пропустил.
```

**Живые данные через коннектор**
```text
Собери дашборд открытых пулл-реквестов, подтягивающий живой список
через мой GitHub-коннектор при загрузке страницы.
```

### Управление

| Действие | Как |
|---|---|
| Открыть последний артефакт | `Ctrl+]` |
| Обновить из этой же сессии | Попросить переопубликовать |
| Обновить из другой сессии | Дать Claude **URL** артефакта — иначе создастся новый |
| Задать заголовок и иконку | Попросить явно: Claude выбирает их сам |
| Галерея всех своих | claude.ai/code/artifacts |

### Снижение стоимости

SVG или HTML/CSS вместо растровых картинок · не добавлять лишнюю интерактивность ·
просить суммировать большие данные, а не встраивать целиком.
