Сверено с code.claude.com/docs/en/artifacts, 20.08.2026.

### Ограничения страницы

| Ограничение | Что означает |
|---|---|
| Внешние запросы | Только Google Fonts и данные коннекторов. CSP режет чужие скрипты, стили, шрифты, картинки, `fetch`, XHR, WebSocket |
| Бэкенд | Нет. Форму не сохранит, зрителя не аутентифицирует |
| Страница | Одна. Относительные ссылки не резолвятся, разделы — якорями |
| Типы файлов | `.html`, `.htm`, `.md` |
| Размер | ≤ **16 МиБ** отрендеренной страницы |

Частая причина отказа публикации по размеру — крупные встроенные картинки.

### Условия доступности (нужны все)

| Требование | Условие |
|---|---|
| План | Pro, Max, Team, Enterprise (на Enterprise включает Owner) |
| Аутентификация | Аккаунт claude.ai через `/login`. API-ключ, gateway-токен, облачные креды — **не могут** |
| Провайдер | Только Anthropic API. Не Bedrock, не Vertex, не Foundry |
| Политика организации | Не включены CMEK, HIPAA, Zero Data Retention |
| Поверхность | CLI 2.1.183+ или десктоп 1.13576.0+ |

Выключено по умолчанию в Agent SDK, GitHub Action и MCP-серверных контекстах,
а также при `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC`.

### Как выключить у себя

| Способ | Значение |
|---|---|
| Файл настроек | `"disableArtifact": true` |
| Переменная окружения | `CLAUDE_CODE_DISABLE_ARTIFACT=1` |
| Правило разрешений | `Artifact` в `permissions.deny` |
| Не открывать браузер | `CLAUDE_CODE_ARTIFACT_AUTO_OPEN=0` |

### Шеринг

- Новый артефакт виден только автору.
- Team/Enterprise — внутри организации; роль **editor** доступна только там.
- Pro/Max — публичная ссылка это **единственный** способ поделиться.
- Артефакт с коннекторами **нельзя** сделать публичным ни на одном плане.
- Просмотрщик грузится с `*.claudeusercontent.com` — добавь в allowlist при фильтрации трафика.

### Снижение стоимости генерации

SVG или HTML/CSS вместо растровых картинок · не добавлять лишнюю интерактивность ·
просить страницу суммировать большие данные, а не встраивать целиком.
