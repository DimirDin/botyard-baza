Сверено с code.claude.com/docs/en/memory, 20.08.2026.

### Чем отличается от CLAUDE.md

| | CLAUDE.md | Автопамять |
|---|---|---|
| Кто пишет | Ты | Claude |
| Что внутри | Инструкции и правила | Выводы и закономерности |
| Область | Проект, пользователь, организация | На репозиторий, общая для worktree |
| Грузится | Целиком каждую сессию | Первые **200 строк или 25 КБ** `MEMORY.md` |

### Где лежит

```text
~/.claude/projects/<project>/memory/
├── MEMORY.md          # индекс, грузится каждую сессию
├── debugging.md       # тематические файлы, грузятся по требованию
└── api-conventions.md
```

`<project>` выводится из git-репозитория, поэтому все worktree и поддиректории делят одну директорию памяти. Вне git используется корень проекта.

### Управление

| Что | Как |
|---|---|
| Посмотреть и править | `/memory` |
| Выключить глобально | тумблер в `/memory` → `autoMemoryEnabled` в `~/.claude/settings.json` |
| Выключить для проекта | `"autoMemoryEnabled": false` в настройках проекта |
| Выключить переменной | `CLAUDE_CODE_DISABLE_AUTO_MEMORY=1` |
| Другое расположение | `"autoMemoryDirectory": "~/my-dir"` (абсолютный путь или `~/`) |

### Важные детали

- Лимит 200 строк / 25 КБ — **только у `MEMORY.md`**. Всё за порогом отбрасывается при загрузке.
- При превышении запись проходит, но возвращается ошибка с требованием переписать индекс.
- Frontmatter и блочные HTML-комментарии в подсчёт лимита **не идут** — они вырезаются.
- Тематические файлы на старте не грузятся — Claude читает их обычными файловыми инструментами.
- Файлы памяти **исключены** из автоматической чистки по `cleanupPeriodDays`.
- Автопамять **машинно-локальна**: между машинами и облачными окружениями не шарится.
- В сабагентов автопамять основного диалога **не грузится** (исключение — форк); своя включается полем `memory`.
- При записи в файл с frontmatter проставляется поле `modified` (ISO 8601), с версии 2.1.214.
