### Автоматически, до первого твоего слова

| Что | Видно тебе? | Заметки |
|---|---|---|
| Системный промпт | нет | Инструкции по поведению, инструментам и формату ответа |
| Автопамять (`MEMORY.md`) | нет | Первые **200 строк или 25 КБ**, что раньше |
| Информация об окружении | нет | Рабочая директория, платформа, шелл, версия ОС, git-репозиторий или нет |
| Имена MCP-инструментов | нет | Полные схемы по умолчанию **отложены** |
| CLAUDE.md | да, в `/context` | Целиком, все найденные по дереву вверх |
| Описания скиллов | нет | Только короткие summary; тело — при вызове |

Git-ветка, статус и последние коммиты грузятся отдельным блоком в самом конце системного промпта.

### Управление загрузкой схем MCP

| Значение | Поведение |
|---|---|
| по умолчанию | Схемы отложены, подгружаются по требованию через tool search |
| `ENABLE_TOOL_SEARCH=auto` | Загружать заранее, если укладываются в 10% окна контекста |
| `ENABLE_TOOL_SEARCH=false` | Загружать всё сразу |

### Что раздувает контекст по ходу сессии

- Чтение крупных файлов и многословный вывод команд — тысячи токенов за один ход.
- История не сбрасывается между ходами внутри сессии — копится всё.
- Каждое определение инструмента едет в **каждый** запрос.
- Подключённый MCP-сервер при отключённом tool search добавляет схемы всех своих инструментов.

### Диагностика

`/context` — что реально загружено, включая раздел **Memory files**.
Хук `InstructionsLoaded` — какие файлы инструкций загрузились, когда и почему.
