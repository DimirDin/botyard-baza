### Где доступен (только платные планы)

| Платформа | Планы |
|---|---|
| Десктоп (macOS/Windows) | Все платные |
| Веб (claude.ai) | Pro, Max, Team |
| Мобильные (iOS/Android) | Pro, Max, Team |
| Боковая панель Chrome | Max, Team, раскатывается на Pro |

### Режимы безопасности

| Режим | Поведение |
|---|---|
| Manual | Останавливается и ждёт одобрения |
| Auto | Claude сам проверяет действие на риски |
| Skip | Автоматических проверок нет |

### Как устроен доступ к файлам

```
Промпт → изолированная среда на серверах Anthropic  (здесь идёт работа)
              ↓ мост
         Claude Desktop на твоём компьютере          (только он видит диск)
              ↓
         подключённые папки с выданным доступом
```

### Что нужно знать заранее

- **Ест лимиты заметно быстрее обычного чата** — режим вычислительно тяжелее.
- Память из чата **не переносится** в Cowork-сессии; исключение — проекты.
- **Шеринг сессий недоступен.**
- Веб и мобильные — бета, раскатка шла волнами начиная с Max.
- Подход Claude показывается до начала выполнения — используй это, чтобы остановить дорогой неверный путь.

### Что делать в каком режиме

| Обратимо | Необратимо → только Manual |
|---|---|
| Собрать черновик, таблицу, разложить файлы | Отправить письмо, ответить в мессенджере |
| Создать новый документ | Перезаписать оригинал, удалить |
| | Поставить встречу в чужой календарь |
