### ❓ Что это

Cowork работает **в изолированных облачных средах на серверах Anthropic** — не на твоей
машине. Это ключевой факт, из которого следует всё остальное поведение.

Чтобы дотянуться до локальных файлов и браузера, Claude «добирается до них через приложение
Claude Desktop на этом компьютере». То есть десктопное приложение выступает мостом между
облачной средой выполнения и твоим диском.

### 🎯 Зачем тебе

Практическое следствие: **папки нужно подключить явно**. Система требует, чтобы ты выдал
Claude соответствующие разрешения на доступ к файлам через подключённые папки — доступа
«ко всему диску по умолчанию» нет.

Отсюда же понятно, почему веб- и мобильная версии ведут себя иначе: без запущенного
десктопного приложения локальные файлы попросту недостижимы, остаётся то, что загружено
или подключено как коннектор.

### 💻 Минимальный пример

Как читать эту архитектуру:

```
Твой промпт
    ↓
Изолированная среда на серверах Anthropic   ← здесь выполняется работа
    ↓ (мост)
Claude Desktop на твоём компьютере          ← только он видит локальный диск
    ↓
Подключённые папки, которым ты выдал доступ ← и только они
```

### ⚠️ Грабли

- **Подключил папку — считай, отдал её содержимое агенту.** Гранулярность разрешений —
  на уровне папки, а не отдельного файла: выбирай узко.
- **Закрыл десктоп — потерял локальный доступ.** Мост держится приложением, не аккаунтом.
- **«Изолированная среда» не означает «твой компьютер».** Ожидания про доступ к локальным
  сервисам, VPN и внутренней сети строятся не отсюда.
