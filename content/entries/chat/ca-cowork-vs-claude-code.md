### ❓ Что это

Cowork описан прямым сравнением: после того как Claude Code изменил разработку ПО,
Cowork приносит ту же исполнительную мощь всем остальным. Движок один — агентный цикл,
инструменты, доведение задачи до конца. Различается поверхность.

### 🎯 Зачем тебе

| | Claude Code | Cowork |
|---|---|---|
| Где живёт | Терминал, IDE, CI, веб, десктоп | Десктоп, веб, мобильные, панель Chrome |
| С чем работает | Репозиторий, файлы кода, git | Файлы, календарь, почта, мессенджеры, веб |
| Кто пользователь | Разработчик | Любой knowledge worker |
| Типичный результат | Коммит, PR, поправленные тесты | Документ, таблица, презентация, сводка |
| Управление доступом | permission-режимы, allow/deny-правила | Manual / Auto / Skip + подключённые папки |

Общее — обе штуки **агентные**: ты формулируешь результат, а не последовательность шагов,
и обе тратят заметно больше вычислений, чем обычный диалог.

### 💻 Минимальный пример

Границу проще всего провести по артефакту:

```
Нужен коммит в репозиторий            → Claude Code
Нужен .xlsx или .docx на выходе        → Cowork
Нужно и то и другое                    → две сессии, не одна
```

Если задача звучит как «разобрать папку с договорами» — это Cowork, даже если ты
разработчик. Если «почини падающие тесты» — это Claude Code, даже если ты не разработчик.

### ⚠️ Грабли

- **Cowork — не замена Claude Code на коде.** Больше 90% его использования — не
  разработка, и продукт затачивался под другое.
- **Память и сессии не общие.** Память из чата в Cowork-сессии не переносится (кроме
  проектов), сессиями поделиться нельзя.
- **Оба режима тратят лимиты быстрее чата.** Считать расход по опыту обычных диалогов —
  верный способ упереться в потолок в середине задачи.
