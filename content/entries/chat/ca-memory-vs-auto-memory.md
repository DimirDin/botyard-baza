### ❓ Что это

Каждая сессия Claude Code начинается с чистого контекстного окна. Знание через границу
сессии переносят два механизма — и путать их не стоит:

| | CLAUDE.md | Автопамять |
|---|---|---|
| **Кто пишет** | Ты | Claude |
| **Что внутри** | Инструкции и правила | Выводы и найденные закономерности |
| **Область** | Проект, пользователь, организация | На репозиторий, общая для worktree |
| **Грузится** | Каждую сессию целиком | Каждую сессию: первые 200 строк или 25 КБ |
| **Для чего** | Стандарты кода, workflow, архитектура | Команды сборки, находки отладки, замеченные предпочтения |

### 🎯 Зачем тебе

Автопамять включена по умолчанию и накапливает знание **без твоего участия**: Claude сам
решает, что стоит запомнить, исходя из того, пригодится ли это в будущем разговоре.
Сохраняет не каждую сессию.

Директория — `~/.claude/projects/<project>/memory/`, внутри `MEMORY.md` как индекс и
тематические файлы. Индекс грузится всегда, тематические файлы — по требованию,
обычными файловыми инструментами.

### 💻 Минимальный пример

```text
~/.claude/projects/<project>/memory/
├── MEMORY.md          # сжатый индекс, грузится каждую сессию
├── debugging.md       # подробности про отладку
└── api-conventions.md # решения по API
```

Посмотреть и отредактировать — командой `/memory`; это обычный markdown, его можно
править и удалять руками. Проверить, что реально загрузилось, — `/context`.

Выключить: тумблер в `/memory`, `"autoMemoryEnabled": false` в настройках проекта или
переменная `CLAUDE_CODE_DISABLE_AUTO_MEMORY=1`.

### ⚠️ Грабли

- **Лимит 200 строк / 25 КБ — только для `MEMORY.md`.** Всё за порогом при следующей
  загрузке отбрасывается. CLAUDE.md грузится целиком независимо от длины (но короткий
  соблюдается лучше).
- **Автопамять переживает чистку старых транскриптов** — файлы памяти исключены из
  автоматической уборки по `cleanupPeriodDays`.
- **Обе системы — контекст, а не принуждение.** Запрет — это `permissions.deny` или хук.
