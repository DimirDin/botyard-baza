### ❓ Что это

В Claude.ai есть два места для «постоянного» контекста, и их часто путают. **Память** — про вас: предпочтения, роль, устойчивые факты, действующие во всех диалогах. **Знания проекта (Projects)** — про конкретную работу: документы, спецификации, код, инструкции, действующие только внутри проекта.

### 🎯 Зачем тебе

| Что нужно сохранить | Куда |
|---|---|
| «Пиши на русском, код с типами» | Память |
| Техническое задание на 40 страниц | Знания проекта |
| «Я тимлид бэкенда» | Память |
| Схема БД конкретного сервиса | Знания проекта |
| «Не используй эмодзи» | Память |
| Гайдлайны стиля этого продукта | Знания проекта |
| Ключ API | Никуда |

**Правило простое:** если факт верен во всех ваших разговорах — это память. Если он верен только в контексте одной работы — это проект.

### 💻 Минимальный пример

Типичная ошибка и её исправление:

```text
❌ Запомни: в проекте Baza схема PostgreSQL называется baza,
   а Redis-префикс — baza:

   → этот факт уедет во все диалоги, включая те, где вы обсуждаете
     совсем другой продукт, и будет всплывать не к месту.

✅ Положить это в знания проекта «Baza».
   В память — только «я работаю с PostgreSQL и Redis».
```

### ⚠️ Грабли

* **Раздутая память ухудшает ответы.** Чем больше нерелевантных фактов подмешивается в каждый диалог, тем выше шанс, что модель зацепится не за то.
* **Проект без структуры — тоже свалка.** Двадцать документов без описания, что из них главное, работают хуже пяти актуальных.
* **Дубли расходятся.** Один и тот же факт в памяти и в проекте рано или поздно начнут противоречить друг другу — храните в одном месте.
