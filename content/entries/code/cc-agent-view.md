### ❓ Что это

**Agent view** — один экран со всеми фоновыми сессиями Claude Code. Каждая из них — полноценный
диалог, который продолжает работать без открытого терминала. Видно, какая сессия **работает**,
какая **ждёт тебя** (жёлтая — вопрос или запрос разрешения), какая **закончила** или упала.
Статус: research preview, интерфейс может меняться.

### 🎯 Зачем тебе

Параллельная работа без десятка вкладок терминала: отправил три задачи в фон, переключился на
четвёртую, вернулся, когда одна из сессий пожелтела. Не нужно читать транскрипты, чтобы понять,
где кто — это видно по строке.

### 💻 Как пользоваться

```bash
claude agents                                 # открыть agent view
claude --bg "разберись с флаки-тестом"        # сразу запустить задачу в фоне
claude --bg --name "flaky-fix" "..."          # то же с именем
claude --bg --exec 'pytest -x'                # фоновая шелл-задача без модели
```

Из уже открытой сессии: `/background` (или `/bg`) уводит её в фон, `/fork` — запускает в фоне
копию, а ты продолжаешь в оригинале.

| Клавиша | Действие |
|---|---|
| `Space` | подсмотреть и ответить, не подключаясь |
| `Enter` / `→` | подключиться к сессии |
| `←` на пустом промпте | отключиться (сессия продолжит работать) |
| `Ctrl+T` | закрепить, чтобы процесс не останавливался в простое |
| `Ctrl+F` | найти сессию по имени |
| `Ctrl+X` | стоп, повторное нажатие за 2 с — удалить |

Фильтры прямо в поле ввода: `s:blocked` — кто ждёт тебя, `n:текст` — по имени.

Для скриптов: `claude agents --json` (поле `state`: `working`, `blocked`, `done`, `failed`,
`stopped`), `claude attach <имя>`, `claude logs <имя>`, `claude stop <id>`.

### ⚠️ Грабли

- **Каждая сессия тратит лимит отдельно.** Десять параллельных сессий выбирают квоту подписки
  примерно в десять раз быстрее одной.
- **Удаление сессии в agent view удаляет и её worktree — с незакоммиченными правками.** По умолчанию
  каждая фоновая сессия работает в своём git worktree в `.claude/worktrees/`. Сначала коммит.
  `claude rm` worktree с незакоммиченными изменениями сохраняет.
- **Сессии живут на твоей машине.** Сон переживают, выключение — нет: после перезагрузки те, что
  работали, будут помечены как failed.
- **Закончившие неподключённые сессии останавливаются примерно через час** ради ресурсов.
  Диалог остаётся на диске и продолжится, если ответить. Нужно держать живой — `Ctrl+T`.
- **Не парси `~/.claude/jobs/`** — формат нестабилен. Для автоматизации есть `claude agents --json`.
- **Monitor-задачи при уходе в фон не переносятся** — Claude Code их остановит, предупредив диалогом.
