### ❓ Что это

Claude Code идёт вверх по дереву каталогов от текущей рабочей директории и в каждой ищет
`CLAUDE.md` и `CLAUDE.local.md`. Все найденные файлы **склеиваются в контекст, а не
переопределяют друг друга**.

Порядок склейки — от корня файловой системы вниз к рабочей директории. Запустился в
`foo/bar/` — значит, `foo/CLAUDE.md` попадёт в контекст раньше, чем `foo/bar/CLAUDE.md`.
Внутри одной директории `CLAUDE.local.md` дописывается после `CLAUDE.md`.

| Область | Расположение |
|---|---|
| Управляемая политика | macOS: `/Library/Application Support/ClaudeCode/CLAUDE.md`; Linux/WSL: `/etc/claude-code/CLAUDE.md`; Windows: `C:\Program Files\ClaudeCode\CLAUDE.md` |
| Пользовательские | `~/.claude/CLAUDE.md` |
| Проектные | `./CLAUDE.md` или `./.claude/CLAUDE.md` |
| Локальные | `./CLAUDE.local.md` (в `.gitignore`) |

### 🎯 Зачем тебе

Из «склеиваются, а не переопределяют» следует главное: **противоречащие друг другу
инструкции не разрешаются автоматически**. Документация формулирует прямо — если два
файла дают разные указания об одном и том же, Claude может выбрать любое.

Проверить, что реально загрузилось в текущую сессию, можно командой `/context` — список
под заголовком **Memory files**.

### 💻 Минимальный пример

Импорт других файлов синтаксисом `@path`:

```text
See @README for project overview and @package.json for available npm commands.

# Additional Instructions
- git workflow @docs/git-instructions.md
```

Относительные пути резолвятся относительно файла с импортом, а не рабочей директории.
Глубина рекурсии — максимум четыре прыжка. Чтобы упомянуть путь без импорта, оберни его
в обратные кавычки.

### ⚠️ Грабли

- **Импорт не экономит контекст.** Импортированные файлы грузятся на старте вместе с
  основным — разбиение помогает организации, но не размеру.
- **Внешний импорт спрашивает разрешение один раз.** Если путь резолвится за пределы
  рабочей директории, Claude Code покажет диалог. Откажешься — импорты останутся
  выключены, и диалог больше не появится.
- **Claude Code читает `CLAUDE.md`, а не `AGENTS.md`.** Если в репозитории уже есть
  `AGENTS.md`, сделай `CLAUDE.md` с импортом `@AGENTS.md`.
- **HTML-комментарии блочного уровня вырезаются** до попадания в контекст — удобно для
  заметок людям, не тратящих токены.
