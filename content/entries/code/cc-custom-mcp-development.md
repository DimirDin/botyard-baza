### ❓ Что это

**Model Context Protocol (MCP)** позволяет подключать к Claude любые внешние инструменты и источники данных. Написание собственного MCP-сервера — это способ дать Claude доступ к специфическому API, корпоративной базе данных или локальным скриптам автоматизации, которых нет в публичных библиотеках.

### 🎯 Зачем тебе

* **Интеграция с внутренними системами**: Вы можете дать Claude доступ к вашему внутреннему API (например, мониторингу или биллингу) для автоматического разбора инцидентов.
* **Кастомные действия с файлами**: Возможность научить Claude специфическим операциям — например, генерации PDF, ресайзу картинок или отправке уведомлений в корпоративный чат.
* **Безопасность**: Весь код MCP-сервера выполняется локально на вашей машине, данные не уходят на сторонние сервера.

### 💻 Как это сделать

Простейший пример MCP-сервера на Python с использованием официального SDK `mcp`. Он будет предоставлять Claude один инструмент — `get_weather`.

1. Установите зависимости:
```bash
pip install mcp uvicorn
```

2. Напишите код сервера в файле `server.py`:
```python
from mcp.server.fastmcp import FastMCP

# Создаем экземпляр сервера
mcp = FastMCP("WeatherService")

# Регистрируем инструмент
@mcp.tool()
def get_weather(city: str) -> str:
    """Возвращает прогноз погоды для указанного города."""
    # Здесь может быть реальный запрос к API weather.com
    if city.lower() == "москва":
        return "В Москве +20°C, солнечно."
    return f"В городе {city} хорошая погода, +22°C."

if __name__ == "__main__":
    mcp.run()
```

3. Подключите его в конфиг Claude Desktop (`claude_desktop_config.json`):
```json
"mcpServers": {
  "my-weather-server": {
    "command": "python",
    "args": ["/полный/путь/к/server.py"]
  }
}
```

### ⚠️ Грабли

* **Используйте Stdio-транспорт**: Для локального использования (например, с Claude Desktop) сервер должен общаться через стандартные потоки ввода-вывода (Stdio). Избегайте использования `print()` в коде инструментов, так как это нарушит протокол обмена данными. Используйте стандартную библиотеку `logging` для вывода логов в `stderr`.
* **Обработка ошибок**: Всегда оборачивайте внешние вызовы (к API или базам данных) в блоки `try-except` и возвращайте Claude понятное текстовое описание ошибки, чтобы модель могла скорректировать свой следующий шаг.
