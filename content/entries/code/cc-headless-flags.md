### ❓ Что это

Headless — запуск Claude Code без интерактива, для скриптов и CI. Включается флагом `-p` / `--print`: агент отрабатывает задачу и печатает результат, ничего не спрашивая. Отсутствие человека рядом означает, что все границы надо задать флагами заранее.

### 🎯 Зачем тебе

| Флаг | Что делает |
|---|---|
| `-p, --print` | Неинтерактивный режим, ответ в stdout |
| `--output-format` | `text` / `json` / `stream-json` — для разбора результата скриптом |
| `--max-turns` | Лимит агентных ходов (только в `-p`) |
| `--max-budget-usd` | Потолок расходов на сессию (только в `-p`) |
| `--bare` | Минимальный старт: без хуков, скиллов, плагинов, MCP и авто-памяти |
| `--tools` | Ограничить инструменты: `""` — все выключить, `"Bash,Edit,Read"` — конкретные |
| `--fallback-model` | Автопереход на другую модель при перегрузке основной |

### 💻 Минимальный пример

```bash
claude -p "Проверь diff на утечки секретов, верни JSON: {findings: [...]}" \
  --output-format json \
  --max-turns 15 \
  --max-budget-usd 2 \
  --tools "Read,Bash(git diff:*)" \
  --fallback-model haiku
```

`--bare` добавляют, когда нужен предсказуемый быстрый прогон: он не подтягивает хуки, скиллы и MCP, из-за чего запуск и быстрее, и воспроизводимее.

### ⚠️ Грабли

* **Без `--max-turns` и `--max-budget-usd` цикл может крутиться долго.** В CI это оплаченное время и оплаченные токены.
* **`claude --help` показывает не все флаги.** Отсутствие флага в help не значит, что его нет — сверяйтесь с документацией CLI.
* **`--output-format json` не гарантирует, что *содержимое* ответа будет валидным JSON.** Структурирована обёртка; то, что просили внутри, всё равно проверяйте.
* **Хуки в CI — источник сюрпризов.** Локально настроенный хук может не существовать на раннере; `--bare` снимает этот класс проблем.
