### ❓ Что это

**Хук** — ваш скрипт, который Claude Code вызывает на определённом событии: перед использованием инструмента, после него, при старте сессии. Хук может не только уведомить, но и **заблокировать** действие, вернув соответствующий результат. Это самый прямой способ поставить жёсткие границы там, где полагаться на «модель поймёт» не хочется.

### 🎯 Зачем тебе

* **Защита секретов.** Хук на чтение файлов отклоняет обращения к `.env`, `id_rsa`, `*.pem` — даже если агент решил, что это ему нужно.
* **Стоп-лист команд.** Блокировка `rm -rf`, `git push --force`, `DROP TABLE` до того, как они выполнятся.
* **Границы каталогов.** Запрет записи вне рабочей директории проекта.
* **Детерминированность.** Хук — это код: он срабатывает всегда, а не «в большинстве случаев».

### 💻 Минимальный пример

Идея хука перед выполнением команды (псевдокод, конкретный формат — в документации):

```bash
#!/usr/bin/env bash
# Читает описание предстоящего вызова инструмента со stdin,
# отклоняет заведомо разрушительные команды.
payload=$(cat)

if echo "$payload" | grep -Eq 'rm[[:space:]]+-rf[[:space:]]+/|git[[:space:]]+push[[:space:]]+--force|DROP[[:space:]]+TABLE'; then
  echo "Заблокировано хуком: разрушительная операция требует ручного запуска" >&2
  exit 2   # ненулевой код = действие не выполняется
fi
exit 0
```

Готовые наборы таких хуков есть в наборе `karanb192/claude-code-hooks` (есть в разделе Инструменты) — там же примеры блокировки чтения `.env`.

### ⚠️ Грабли

* **Хук выполняется с вашими правами.** Чужой хук — это чужой код у вас на машине с полным доступом. Читайте перед установкой.
* **Регулярки обходятся тривиально.** `rm -rf /` ловится, `rm  -rf  /` с двойными пробелами или `bash -c` с кодированной строкой — уже нет. Хук защищает от случайности и невнимательности, а не от целенаправленного обхода.
* **Ложные срабатывания раздражают и их отключают.** Слишком широкий стоп-лист приводит к тому, что защиту просто снимают.
* **Не замена изоляции.** Настоящая граница — контейнер или отдельная машина, см. статью «Sandboxing в Claude Code».
