### ❓ Что это

Режим доступа определяет, что Claude Code делает без вопросов, а что выносит на подтверждение. Переключение на лету — **Shift+Tab** циклически проходит по режимам. Стартовый режим задаётся флагом `--permission-mode` или полем `defaultMode` в `settings.json`.

### 🎯 Зачем тебе

| Режим | Поведение | Когда уместен |
|---|---|---|
| `default` | Спрашивает на каждое потенциально опасное действие | Незнакомый проект, чувствительный код |
| `acceptEdits` | Правки файлов без вопросов, остальное как в default | Понятная задача с большим числом мелких правок |
| `plan` | Сначала анализ и план, правок нет до одобрения | Начало работы, разбор чужого кода |
| `auto` | Классификатор сам решает, что безопасно | Повседневная работа в своём проекте |
| `dontAsk` | Разрешены только заранее одобренные инструменты | Автоматизация с фиксированным набором действий |
| `bypassPermissions` | Пропускает все проверки | Только изолированное окружение |

### 💻 Минимальный пример

```bash
# начать с плана, ничего не трогая
claude --permission-mode plan

# режим на всю сессию через settings.json
{ "defaultMode": "acceptEdits" }
```

Практичный рабочий цикл: `plan` для разбора задачи → одобрили план → Shift+Tab в `acceptEdits` для исполнения.

### ⚠️ Грабли

* **`bypassPermissions` — осознанный компромисс, а не ускоритель.** Флаг `--dangerously-skip-permissions` делает то же самое. Использовать только в контейнере или тестовой VM, никогда — в проекте с непроверенными зависимостями.
* **`acceptEdits` не спрашивает про правки, но это не «безопасный режим».** Агент может переписать то, что вы не собирались менять; спасает git, а не режим.
* **`dontAsk` требует заранее продуманного списка.** Забыли инструмент — работа встанет посреди процесса.
