### ❓ Что это

Безопасность MCP-серверов — это комплекс архитектурных мер и настроек доступа, предотвращающий несанкционированное чтение файлов, утечку API-ключей и выполнение произвольного кода агентами через протокол Model Context Protocol (MCP).

Так как MCP-серверы выполняются в контексте безопасности локального пользователя или контейнера, скомпрометированный или ненадёжный MCP-инструмент может получить полный доступ к файловой системе, базе данных и учетным данным проекта.

---

### 🎯 Для чего

1. **Защита от Indirect Prompt Injection**: Предотвращение выполнения опасных команд, скрытых в содержимом загружаемых веб-страниц или входящих тикетов.
2. **Ограничение прав на запись в БД**: Настройка доступа к PostgreSQL/MySQL только в режиме Read-Only при выполнении исследовательских запросов.
3. **Изоляция системных вызовов**: Запуск системных MCP-серверов внутри защищённых Docker-контейнеров с ограниченными лимитами CPU/RAM.

---

### 💻 Как настроить и обезопасить

#### 1. Ограничение прав в `claude.json` / `.mcp.json`
Всегда прописывайте доступ только к нужным каталогам в аргументах запуска серверных CLI:

```json
{
  "mcpServers": {
    "filesystem": {
      "type": "stdio",
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-filesystem",
        "/Users/dev/project/allowed-dir"
      ]
    }
  }
}
```

#### 2. Запуск MCP в изоляции Docker
Для предотвращения случайного доступа к остальной системе запускайте тяжелые или сторонние MCP-серверы в изолированных контейнерах:

```bash
claude mcp add postgres -- docker run -i --rm -e POSTGRES_URL=postgres://readonly:pass@db:5432/app mcp/postgres
```

---

### ⚠️ Грабли

- **Передача root-прав**: Никогда не запускайте MCP-серверы от имени пользователя `root` или с флагами `--privileged` без жесткой необходимости.
- **Хранение секретов в репо**: Конфиг `.mcp.json` с уровнем `project scope` может случайно попасть в Git вместе с API-ключами. Используйте переменные окружения (`$ENV_VAR`) вместо открытых ключей.
- **Избыток подключённых инструментов**: Подключение более 10–12 MCP-серверов не только увеличивает токены расхода, но и расширяет поверхность возможной атаки.
