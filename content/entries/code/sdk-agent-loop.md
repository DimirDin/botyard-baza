### ❓ Что это

Каждая сессия агента идёт по одному и тому же циклу:

1. **Получить промпт** — вместе с системным промптом, определениями инструментов и историей.
   SDK отдаёт `SystemMessage` с подтипом `"init"`.
2. **Оценить и ответить** — модель отвечает текстом, запросом инструментов или тем и другим
   сразу. SDK отдаёт `AssistantMessage`.
3. **Выполнить инструменты** — SDK запускает каждый запрошенный инструмент и собирает результаты.
4. **Повторить** — шаги 2–3 крутятся. Один полный проход — это **один ход** (turn).
5. **Вернуть результат** — финальный `AssistantMessage` без вызовов инструментов, следом
   `ResultMessage` с текстом, расходом токенов, стоимостью и `session_id`.

### 🎯 Зачем тебе

Понимание «хода» — это понимание счёта. Простой вопрос («какие тут файлы?») — один-два хода.
«Отрефактори модуль авторизации и обнови тесты» — десятки вызовов инструментов через много ходов.
Именно ходами и деньгами ты цикл и ограничиваешь.

| Опция | Что ограничивает | По умолчанию |
|---|---|---|
| `max_turns` / `maxTurns` | Число ходов с вызовом инструментов | без лимита |
| `max_budget_usd` / `maxBudgetUsd` | Потраченные деньги | без лимита |

Бюджет **покрывает и сабагентов** — их траты идут в общий счёт. Когда потолок достигнут,
запуск нового сабагента падает с `Budget limit reached`, а фоновые останавливаются.

### 💻 Минимальный пример

Пять типов сообщений, которые отдаёт поток:

| Тип | Когда приходит |
|---|---|
| `SystemMessage` | события жизненного цикла: `init`, `compact_boundary`, `informational` |
| `AssistantMessage` | после каждого ответа модели, включая финальный |
| `UserMessage` | после выполнения инструмента — с его результатом |
| `StreamEvent` | только при включённых частичных сообщениях |
| `ResultMessage` | конец цикла: текст, usage, стоимость, `session_id` |

```python
async for message in query(prompt="Почини падающие тесты", options=opts):
    if isinstance(message, ResultMessage):
        if message.subtype == "success":
            print(message.result)
        elif message.subtype == "error_max_turns":
            print(f"Кончились ходы. Возобнови сессию {message.session_id}")
```

### ⚠️ Грабли

- **Поле `result` есть только у подтипа `success`.** У `error_max_turns`,
  `error_max_budget_usd`, `error_during_execution` его нет — всегда проверяй `subtype` до чтения.
- **Одиночный `query()` бросает исключение после ошибочного результата.** Сначала отдаёт
  `ResultMessage`, потом кидает — это сделано намеренно, оборачивай в `try`.
- **Не обрывай поток на `ResultMessage`.** После него может прийти небольшой хвост системных
  событий (`prompt_suggestion`) — дочитывай итератор до конца.
- **В Python `total_cost_usd`, `usage` и `model_usage` типизированы как опциональные** —
  проверяй на `None`, иначе поймаешь падение на ровном месте.
- **`usage` считает только основной цикл.** Для всего дерева, включая сабагентов, бери
  `model_usage` / `modelUsage`.
