### ❓ Что это

Контекст **не сбрасывается между ходами внутри сессии** — накапливается всё: системный промпт,
определения инструментов, история, входы и выходы инструментов.

| Источник | Когда грузится | Во что обходится |
|---|---|---|
| Системный промпт | Каждый запрос | Небольшая фиксированная плата |
| CLAUDE.md | Старт сессии, через `settingSources` | Целиком в каждый запрос, но кэшируется |
| Определения инструментов | Каждый запрос; MCP-схемы отложены по умолчанию | Встроенные грузятся всегда |
| История диалога | Копится по ходам | Растёт с каждым ходом |
| Описания скиллов | Старт сессии | Короткие summary; тело грузится при вызове |

### 🎯 Зачем тебе

Большие выводы инструментов жрут контекст незаметно: чтение крупного файла или команда с
многословным выводом — тысячи токенов за один ход. Длинная сессия с десятками вызовов
накапливает несопоставимо больше короткой.

Что с этим делают:

- **Сабагенты на подзадачи.** Каждый стартует с чистым диалогом, не видит ходов родителя, и
  наверх возвращается **только финальный ответ**. Контекст родителя растёт на summary, а не на
  весь транскрипт подзадачи.
- **Скупость на инструменты.** Каждое определение занимает место — сужай набор через поле
  `tools` у сабагента.
- **Внимание к MCP.** Когда tool search выключен или откатился к предзагрузке, каждый сервер
  добавляет схемы всех своих инструментов в каждый запрос.
- **Низкий `effort` на рутине.** Для агента, который только читает файлы, `"low"` экономит
  и токены, и деньги.

### 💻 Минимальный пример

Когда контекст подходит к пределу, SDK **сам** сжимает диалог: суммаризует старую историю,
сохраняя недавние обмены и ключевые решения. В поток приходит сообщение с
`subtype: "compact_boundary"`.

Компактацией можно управлять — например, объяснить компактору, что беречь, прямо в CLAUDE.md:

```markdown
# Инструкции по суммаризации

При сжатии этого диалога всегда сохраняй:
- текущую задачу и критерии приёмки
- пути файлов, которые читали или меняли
- результаты тестов и тексты ошибок
- принятые решения и их обоснование
```

Заголовок секции произвольный — компактор ориентируется на смысл. Ещё есть хук `PreCompact`
(например, чтобы заархивировать полный транскрипт) и ручная компактация промптом `/compact`.

### ⚠️ Грабли

- **Компактация заменяет старые сообщения summary — инструкции из начала диалога могут не
  пережить её.** Поэтому постоянные правила место не в первом промпте, а в CLAUDE.md:
  его содержимое переинжектится в каждый запрос заново.
- **Кэш экономит, но не отменяет расход.** Неизменная часть (системный промпт, определения
  инструментов, CLAUDE.md) кэшируется — полную цену платит только первый запрос.
- **Сабагент не наследует историю родителя, но своё окружение грузит.** Свой системный промпт
  и проектный контекст вроде CLAUDE.md он всё равно поднимает.
