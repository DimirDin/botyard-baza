### ❓ Что это

SDK везёт те же инструменты, что и Claude Code:

| Категория | Инструменты |
|---|---|
| Файлы | `Read`, `Edit`, `Write` |
| Поиск | `Glob`, `Grep` |
| Выполнение | `Bash` |
| Веб | `WebSearch`, `WebFetch` |
| Обнаружение | `ToolSearch` — грузит инструменты по требованию вместо предзагрузки |
| Оркестрация | `Agent`, `Skill`, `AskUserQuestion`, `TaskCreate`, `TaskUpdate` |

Сверх этого — MCP-серверы, свои инструменты через custom tool handlers и проектные скиллы.

### 🎯 Зачем тебе

**Хуки** — колбэки, срабатывающие в конкретных точках цикла:

| Хук | Когда | Типичное применение |
|---|---|---|
| `PreToolUse` | До выполнения инструмента | Валидация входа, блокировка опасных команд |
| `PostToolUse` | После возврата | Аудит, побочные эффекты |
| `UserPromptSubmit` | При отправке промпта | Подмешать контекст |
| `Stop` | Когда агент закончил | Проверить результат, сохранить состояние |
| `SubagentStart` / `SubagentStop` | Запуск/финиш сабагента | Учёт параллельных задач |
| `PreCompact` | До сжатия контекста | Заархивировать транскрипт |

Главное свойство: **хуки выполняются в процессе твоего приложения, а не внутри контекстного
окна агента** — значит, они не тратят контекст вообще. И они умеют коротко замыкать цикл:
`PreToolUse`, отклонивший вызов, не даст инструменту выполниться, а модель получит отказ.

### 💻 Минимальный пример

Параллельность зависит от природы инструмента:

- **Только читающие** (`Read`, `Glob`, `Grep`, MCP-инструменты, помеченные read-only) могут
  выполняться одновременно.
- **Меняющие состояние** (`Edit`, `Write`, `Bash`) — строго последовательно, чтобы не
  конфликтовать.
- **Свои инструменты по умолчанию последовательны.** Чтобы разрешить параллель, выстави
  `readOnlyHint` в аннотациях — имя поля пришло из MCP SDK и одинаково в обоих языках.

```python
options = ClaudeAgentOptions(
    allowed_tools=["Read", "Edit", "Bash", "Glob", "Grep"],
    setting_sources=["project"],   # подхватить CLAUDE.md, скиллы и хуки из текущей папки
    max_turns=30,
    effort="high",
)
```

### ⚠️ Грабли

- **Набор хуков в двух SDK не совпадает.** У TypeScript есть события, которых в Python пока
  нет — сверяйся со списком, а не с памятью.
- **Без `setting_sources` проект не подхватится.** CLAUDE.md, скиллы и файловые хуки грузятся
  только когда ты явно указал источники настроек.
- **`ToolSearch` — это про экономию контекста, а не про удобство.** Он откладывает загрузку
  схем, но на неподдерживаемых моделях и некоторых платформах откатывается к предзагрузке —
  и тогда экономии нет.
