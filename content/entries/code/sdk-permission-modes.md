### ❓ Что это

Модель сама решает, **какие** инструменты звать, а ты решаешь, **позволено ли** им выполниться.
Три опции работают вместе:

- `allowed_tools` / `allowedTools` — автоодобрение перечисленных. Не попавшие в список
  остаются доступны, но требуют разрешения.
- `disallowed_tools` / `disallowedTools` — жёсткая блокировка, вне зависимости от остального.
- `permission_mode` / `permissionMode` — сколько человеческого надзора ты хочешь в принципе.

### 🎯 Зачем тебе

| Режим | Поведение | Для чего |
|---|---|---|
| `default` | Не покрытое allow-правилами уходит в `canUseTool`; нет колбэка — значит отказ | Интерактивные приложения со своим окном одобрения |
| `acceptEdits` | Автоодобряет правки файлов и обычные ФС-команды (`mkdir`, `touch`, `mv`, `cp`); остальной Bash — по общим правилам | Прототипирование, работа в изолированной папке |
| `plan` | Исследует и планирует, исходники не правит | Ревью, одобрение изменений до применения |
| `dontAsk` | Никогда не спрашивает: что разрешено правилами — выполняется, остальное отклоняется | Headless-агент с фиксированной поверхностью инструментов |
| `auto` | Классификатор-модель сама одобряет или отклоняет запросы | Автономные агенты, которым всё же нужны ограничители |
| `bypassPermissions` | Всё разрешённое выполняется без вопросов | Только CI, контейнеры, изолированные среды |

### 💻 Минимальный пример

Набор инструментов задаёт класс агента:

| Инструменты | Что агент может |
|---|---|
| `Read`, `Glob`, `Grep` | Только чтение и анализ |
| `Read`, `Edit`, `Glob` | Анализ и правка кода |
| `Read`, `Edit`, `Bash`, `Glob`, `Grep` | Полная автоматизация |

```python
options = ClaudeAgentOptions(
    allowed_tools=["Read", "Glob", "Grep"],   # агент только для чтения
    permission_mode="default",
)
```

Отдельные инструменты можно сузить правилом вида `"Bash(npm *)"` — разрешить только конкретные команды.

### ⚠️ Грабли

- **`bypassPermissions` — не «просто побыстрее».** Документация ограничивает его изолированными
  средами, где действия агента не заденут ничего важного. В TypeScript он вдобавок требует
  `allowDangerouslySkipPermissions: true`, а под root на Unix не работает вовсе.
- **Даже `bypassPermissions` не обходит всё.** Инструменты с явным правилом `ask`, коннекторные
  инструменты, которым организация выставила `ask`, и инструменты, требующие участия человека,
  всё равно не пройдут.
- **`dontAsk` — это жёсткий deny, а не тишина.** `AskUserQuestion` и MCP-инструменты с
  `requiresUserInteraction` в нём отклоняются, даже если ты их разрешил.
- **Отказ не останавливает агента.** Модель получает отказ как результат инструмента и
  обычно пробует другой путь — планируй, что она попробует обойти.
