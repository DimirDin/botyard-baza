### ❓ Что это

Артефакт — **одна самодостаточная страница**, завёрнутая в HTML-оболочку и отдаваемая под
строгим Content Security Policy. Формулировка документации точна: это «снимок работы, а не
приложение».

| Ограничение | Что означает на практике |
|---|---|
| Внешние запросы | Кроме Google Fonts и данных коннекторов снаружи не приходит ничего: CSP режет чужие скрипты, стили, шрифты, картинки, а также `fetch`, XHR и WebSocket |
| Нет бэкенда | Страница не сохранит данные из формы и не аутентифицирует зрителя сама |
| Одна страница | Относительные ссылки не резолвятся — рядом ничего не задеплоено; для разделов используются якоря |
| Типы файлов | Только `.html`, `.htm` или `.md` (Markdown рендерится в стилизованный HTML) |
| Размер | Отрендеренная страница — не больше **16 МиБ** |

### 🎯 Зачем тебе

Эти рамки объясняют, почему Claude инлайнит CSS и JS и встраивает картинки как data URI —
не из любви к однофайловости, а потому что иначе страница не отрисуется.

И они же задают границу применимости: если нужен внутренний инструмент с бэкендом,
документация прямо советует деплоить его у себя, а не пытаться выжать из артефакта.

### 💻 Минимальный пример

Что укладывается в рамки, а что нет:

```
Работает:  дашборд по данным, собранным в сессии
           сравнение четырёх вариантов лейаута на одной странице
           интерактивные слайдеры, меняющие превью на лету
           чек-лист, который агент отмечает по ходу длинной задачи

Не работает: форма, сохраняющая ответы
             логин зрителей
             несколько маршрутов/страниц
             обращение к своему API
```

### ⚠️ Грабли

- **Падение публикации по размеру почти всегда — крупные встроенные картинки.** Это прямо
  названо типовой причиной.
- **Относительные ссылки молча не работают.** Не «ведут не туда», а не резолвятся вовсе.
- **Google Fonts — единственный внешний источник шрифтов.** Любой другой шрифт инлайнится
  как `@font-face` data URI.
