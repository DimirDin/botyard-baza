### ❓ Что это

Генерация артефакта расходует выходные токены, как любой другой ответ, но
**стилизованная страница токеноёмче, чем то же содержимое обычным текстом**.

Главные источники расхода названы прямо:

1. Инлайновый CSS.
2. JavaScript для интерактивных контролов.
3. **Особенно** — картинки, встроенные как data URI.

### 🎯 Зачем тебе

Официальные способы снизить стоимость:

- **Предпочитать SVG либо HTML и CSS** для схем вместо встроенных растровых изображений.
- **Не добавлять интерактивность, которая не нужна.**
- **Просить страницу суммировать большие данные**, а не встраивать их целиком.

Третий пункт самый недооценённый: дашборд по десяти тысячам строк не обязан содержать
десять тысяч строк — ему нужны агрегаты.

### 💻 Минимальный пример

Одна и та же задача, разная цена:

```
Дорого:  «Сделай дашборд со всеми записями таблицей и графиками»
Дёшево:  «Сделай дашборд: топ-10 по объёму, агрегаты по неделям, остальное — числом»

Дорого:  схема архитектуры картинкой
Дёшево:  та же схема inline-SVG
```

### ⚠️ Грабли

- **Растровая картинка бьёт дважды** — по токенам при генерации и по лимиту 16 МиБ
  при публикации.
- **«Пусть будет интерактивно» стоит денег.** Каждый слайдер — это код в выводе.
- **Перепубликация — новая генерация.** Артефакт, обновляемый на каждом шаге длинной
  задачи, платит за каждое обновление.
