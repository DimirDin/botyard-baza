### ❓ Что это

**Task budget** — потолок в токенах на агентный цикл, о котором модель **знает**. Сервер
подмешивает счётчик обратного отсчёта, который Claude видит во время генерации, и агент
распределяет силы: успевает свернуться и отдать результат, а не обрывается на полуслове.

Принципиальное отличие от `max_tokens`:

| | `max_tokens` | `task_budget` |
|---|---|---|
| Природа | жёсткий потолок ответа | рекомендательный бюджет задачи |
| Модель знает? | **нет** | **да**, видит счётчик |
| Что происходит на пределе | обрыв | агент завершает работу |

Бета `task-budgets-2026-03-13`, модели: **Opus 5, Fable 5, Sonnet 5, Opus 4.8, Opus 4.7**.
Минимальный `total` — **20 000**.

### 🎯 Зачем тебе

Долгий агент с инструментами, который иначе либо уходит в бесконечное исследование,
либо обрывается ровно тогда, когда собрался написать вывод.

### 💻 Минимальный пример

`task_budget` лежит **внутри `output_config`**. Стриминг обязателен — иначе большой `max_tokens`
упрётся в HTTP-таймаут:

```python
with client.beta.messages.stream(
    model="claude-opus-5",
    max_tokens=128000,
    output_config={"effort": "high", "task_budget": {"type": "tokens", "total": 64000}},
    betas=["task-budgets-2026-03-13"],
    messages=[...], tools=[...],
) as stream:
    response = stream.get_final_message()
```

Бюджет считает то, что Claude **генерирует**, плюс результаты инструментов, прочитанные
на этом ходу. Историю, которую ты пересылаешь каждым запросом, он не считает.

### ⚠️ Грабли

- **Не передавай `remaining` в обычном цикле.** Сервер сам ведёт отсчёт. Клиентский `remaining`
  вместе с пересылкой полной истории занижает бюджет. Передавать его нужно **только** если ты
  компактишь или переписываешь историю между запросами и сервер уже не может вывести трату сам.
- **Это не бюджет сессии Managed Agents.** Тот — жёсткий, в долларах, его держит платформа.
  Этот — рекомендательный, в токенах. Похожие слова, разные механизмы.
- **Только Messages API.** У CMA своя система бюджетов без ограничения по классу модели.
- **Меньше 20 000 нельзя** — запрос не пройдёт валидацию.
