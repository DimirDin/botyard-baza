### ❓ Что это

**Admin API** (бета с 26.08.2026) — управление организацией из кода: участники и приглашения,
воркспейсы и их состав, API-ключи, отчёты по рейт-лимитам, сервисные аккаунты, правила
и издатели федерации, внешние ключи CMEK.

В SDK живёт под `client.beta.organization`, в CLI — `ant beta:organization`. Доступно
во всех семи SDK.

### 🎯 Зачем тебе

Всё, что иначе делается руками в консоли: онбординг сотрудника в нужный воркспейс, ротация
ключей по расписанию, аудит того, у кого какой доступ, заведение сервисных аккаунтов под CI.

### 💻 Минимальный пример

```python
from anthropic import Anthropic

client = Anthropic()      # нужен админский креденшел, см. ниже
members = client.beta.organization.members.list()
```

Нужен **админский** креденшел, обычный ключ отвергается:

| Тип | Как выглядит | Откуда читается |
|---|---|---|
| Admin API key | `sk-ant-admin...` | `ANTHROPIC_API_KEY` |
| OAuth-токен со скоупом `org:admin` | — | `ANTHROPIC_AUTH_TOKEN` |

### ⚠️ Грабли

- **Обычный API-ключ не подойдёт.** Ошибка при этом выглядит как проблема прав, а не как
  «взял не тот ключ» — легко уйти отлаживать не туда.
- **Отчётов по расходам и потреблению в SDK нет.** Usage & Cost endpoints, а также
  user-management и аналитика Claude Enterprise доступны **только через сырой HTTP**.
  Если планируешь дашборд по тратам — закладывай прямые запросы, а не метод SDK.
- **Admin-ключ мощнее обычного на порядок.** Он не должен лежать там же, где рантайм-ключи
  приложения, и тем более уезжать в общий `.env`.
