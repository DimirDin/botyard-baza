### ❓ Что это

Managed Agents тарифицируется по **двум** измерениям одновременно:

1. **Токены** — по обычным ставкам модели, множители prompt caching работают как везде.
2. **Время сессии** — **$0.08 за час сессии**, считается по миллисекундам.

Время идёт **только пока статус `running`**. `idle` (ждём сообщение или подтверждение тула),
`rescheduling` и `terminated` не тарифицируются.

Session runtime **заменяет** почасовую оплату контейнера из code execution — двойной оплаты нет.

### 🎯 Зачем тебе

Понять, что дорогое в агенте, а что нет. Час висения в `idle` бесплатен; час активной работы
стоит восемь центов сверх токенов. На практике runtime почти всегда копейки на фоне токенов —
но в ночных деплоях, которые крутятся каждый день, он становится заметен.

### 💻 Минимальный пример

Часовая сессия на Opus 5, 50 000 входных и 15 000 выходных токенов:

| Строка | Расчёт | Стоимость |
|---|---|---|
| Input | 50 000 × $5 / 1M | $0.25 |
| Output | 15 000 × $25 / 1M | $0.375 |
| Runtime | 1.0 ч × $0.08 | $0.08 |
| **Итого** | | **$0.705** |

Если 40 000 входных токенов пришли из кэша, input падает до $0.05 + $0.02, и общая сумма
становится $0.525.

Жёсткий предохранитель — **бюджет сессии**: платформенный лимит в долларах на одну сессию.

### ⚠️ Грабли

- **Batch-скидка 50% не применяется.** Сессии интерактивные и stateful, батча тут нет.
- **Бюджет сессии ≠ task budget.** Бюджет сессии — жёсткий, в долларах, его держит платформа.
  Task budget из Messages API — рекомендательный, в токенах, модель просто видит счётчик.
  Разные вещи с похожими названиями.
- **`inference_geo` на CMA живёт внутри объекта `model` агента**, а не на верхнем уровне запроса,
  как в Messages API. Пин на `us` даёт множитель 1.1× к токенам сессий.
- **Fast mode тоже стоит денег** — если у агента `model.speed = "fast"`, применяется премиальный тариф.
