### ❓ Что это
Headless — запуск Claude Code без интерактива: флаг `-p` с промптом и `--output-format json` для машиночитаемого ответа. Это же основной способ использовать агента из языка, для которого нет SDK.

### 🎯 Зачем тебе
Автоматическое ревью каждого пулл-реквеста, генерация changelog на релизе, регулярная проверка на устаревшие зависимости — всё, что не требует человека в цикле.

### 💻 Как это выглядит на практике
```bash
claude -p "проверь диф на регрессии" --output-format json --setting-sources user
```

Флаг `--setting-sources` здесь не украшение, а вопрос безопасности. По умолчанию агент прочитает `CLAUDE.md` и `.claude/rules/` из проверяемой ветки — а её содержимое пишет автор пулл-реквеста, в том числе внешний. **Инструкции из ветки — это ввод, а не конфигурация.** Настоящая защита живёт в managed-настройках и хуках.

Отдельно стоит знать: в контекстах Agent SDK, GitHub Action и MCP-сервера артефакты выключены по умолчанию, а сессия на API-ключе не может их публиковать вовсе.

### ⚠️ Частая ошибка новичка
Запустить в CI без потолка по ходам и деньгам. В интерактиве ты видишь, что агент буксует, и останавливаешь его. В CI не видит никто — считать будет счёт.
