# Редизайн Mini App «Baza без воды» — Anthropic Studio

Дата: 2026-07-25
Статус: спека согласована, план реализации не написан

## 1. Что делаем и чего не делаем

Меняем **только внешний слой** Mini App. Механика, роутинг, гейт подписки, контракты API,
контент-пайплайн и бэкенд не трогаются — ни одного изменения в `backend/`, `bot/`, `db/`,
`content/`, `scripts/`.

Три решения, принятые по кликабельным прототипам:

| Решение | Выбор |
|---|---|
| Визуальное направление | **Anthropic Studio** — тёплая бумажная палитра, антиква в заголовках, карточки-плитки с обложками |
| Тема | **Только тёмная.** Светлая версия из прототипа не реализуется |
| Фон | **Гибрид:** видео-угольки на витрине, canvas-пыль на остальном |
| Полный экран | **Да**, `requestFullscreen()` сразу при открытии, с фоллбэком |
| Иконки | **Вторая волна.** Работаем на текущих 153 PNG |

Терминальная эстетика oh-my-zsh уходит: промпт-строка `➜ baza git:(...)`, дерево `├── └──`,
braille-спиннер и тосты-exit-коды перестают быть визуальным языком продукта. Это осознанный
разрыв с §13 внешнего `BAZA_CONTEXT.md`, который надо будет переписать (см. §9).

## 2. Дизайн-система

Сейчас токенов почти нет: `tokens.css` — 24 строки, только цвета. Отступы, радиусы, тени и
тайминги живут в 510 строках `global.css` и в инлайновых `style={{...}}` почти каждого экрана.
Из-за этого редизайн «в лоб» означает правку двадцати файлов. Первым делом строим полный
токен-слой, и дальше всё стилизуется через него.

### 2.1. Цвет

```
--bg              #16130F   тёплый почти-чёрный, «прокопчённая бумага»
--surface         #201C17   карточки, панели, навигация
--surface-2       #2B251E   вложенные плашки, код, треки прогресса
--line            #332C24   границы
--text            #F5EFE4   заголовки
--text-2          #C4B9A8   тело
--text-3          #8B8072   подписи, мета
--accent          #E08256   терракота
--accent-ink      #1A1410   текст на акценте
--seg-what        #8FBF83
--seg-why         #7FB2CF
--seg-example     #B394CB
--seg-gotcha      #D9614A   намеренно отличается от --accent
--seg-source      #8B8072
--error           #D9614A
```

Пять цветов сегментов статьи сохраняются как смысловая система (что это / зачем тебе / пример /
грабли / источник) — меняются только значения под тёмную бумагу.

### 2.2. Типографика

| Роль | Гарнитура | Где |
|---|---|---|
| Дисплей | Literata Variable | заголовки экранов, заголовки карточек, `h2` статей |
| Тело | системный sans | текст статей, описания |
| Данные | JetBrains Mono Variable | счётчики, мета, код, лейблы, табы |

Обе веб-гарнитуры вшиваются в бандл (`@fontsource-variable/...`), не тянутся с CDN. **При
подключении обязательно проверить наличие кириллического сабсета у Literata** — если его нет,
берём Source Serif 4 или PT Serif. JetBrains Mono кириллицу поддерживает.

Сейчас `--font-mono` объявлен в `tokens.css`, но нигде не подключён — весь «терминальный»
характер рендерится системным фоллбэком. Это чинится здесь же.

Шкала кегля: `11 / 12 / 13.5 / 15 / 17 / 21 / 25 / 29`. Тело статей — 15 px, интерлиньяж 1.66.

## 3. Полный экран и безопасные зоны

### 3.1. Что меняется в `lib/telegram.js`

Сейчас там только `ready()` + `expand()`. Добавляется:

```js
tg.ready();
tg.expand();                                   // база для клиентов < 8.0
if (tg.isVersionAtLeast("7.7")) tg.disableVerticalSwipes();
if (tg.isVersionAtLeast("8.0")) {
  tg.onEvent("fullscreenChanged", syncFullscreen);
  tg.onEvent("fullscreenFailed",  syncFullscreen);
  tg.onEvent("safeAreaChanged",        syncInsets);
  tg.onEvent("contentSafeAreaChanged", syncInsets);
  tg.requestFullscreen();
}
```

`syncFullscreen` ставит `data-fullscreen="on|off"` на `<html>`, `syncInsets` копирует
`tg.safeAreaInset` и `tg.contentSafeAreaInset` в CSS-переменные. Вёрстка обязана выглядеть
корректно в обоих состояниях — на клиентах старше Bot API 8.0 останется нынешний режим.

### 3.2. Источник отступов

Сейчас в `tokens.css` стоит `--safe-top: env(safe-area-inset-top, 44px)`. Внутри вебвью Telegram
этот механизм работает ненадёжно — именно поэтому Telegram завёл собственные переменные.
Переходим на них:

```css
--safe-top:         var(--tg-safe-area-inset-top, 0px);
--safe-bottom:      var(--tg-safe-area-inset-bottom, 0px);
--content-safe-top: var(--tg-content-safe-area-inset-top, 0px);
```

Никаких констант высоты чёлки в коде быть не должно: на Android вырез меньше, а нижняя панель
бывает жестовой или трёхкнопочной.

### 3.3. Следствия для интерфейса

- **Хедер** отступает сверху на `--safe-top + --content-safe-top`.
- **Кнопка поиска переезжает влево.** В фуллскрине правый верхний угол занимают плавающие
  «✕» и «⋮» Telegram — сейчас там стоит поиск, он оказался бы прямо под крестиком.
- **Скрим сверху обязателен.** Кнопки Telegram белые и рисуются поверх фона; на светлых кадрах
  ролика они пропадают. Ставим градиент от `--bg` вниз до прозрачного на высоту
  `--content-safe-top + 26px`.
- **Нижняя навигация** получает `padding-bottom: var(--safe-bottom)`, иначе «Моё» перехватывается
  системным жестом.
- `disableVerticalSwipes()` не опция: в фуллскрине свайп вниз по статье закрывал бы приложение.

## 4. Фон

### 4.1. Исходники и обработка

Три ролика лежат в `content-factory/motion-engine/backgrounds/` (вне этого репозитория). Взят
**`bg_style_1` — угольки**. Два других отклонены: второй уходит в холодную синеву и конфликтует
с терракотой, третий слишком плотный и перебивает текст.

Обработка (уже выполнена, файлы готовы):

| Проблема | Что сделано |
|---|---|
| 7,5 МБ | Даунскейл до 480×854, 20 fps, CRF 32 → **439 КБ** |
| Первый и последний кадр разные, луп рвётся | Хвост 1,2 с наложен кросс-фейдом на начало, длина 8,8 с |
| AAC-дорожка внутри | Вырезана — без этого Telegram блокирует автоплей |

Файлы кладутся в `frontend/public/bg/embers.mp4` и `embers-poster.jpg` (первый кадр, показывается
до загрузки видео).

### 4.2. Компонент `AmbientBackground`

Единая точка ответственности за фон. Пропс `variant`:

| variant | Что рисует | Где применяется |
|---|---|---|
| `video` | тёплая градиентная заливка + `embers.mp4` через `mix-blend-mode: screen` + зерно | гейт-экран, Главная |
| `dust` | та же заливка + canvas-частицы + зерно | все остальные экраны |
| `wash` | только заливка + зерно | reduced-motion, отключённый фон |

Правила:

- Видео: `muted loop playsinline preload="none"`, `poster` — первый кадр. Загружается лениво,
  только когда пользователь впервые попадает на экран с `variant="video"`.
- Автоплей: попытка `play()` при монтировании; при отказе — повтор по первому
  `pointerdown`/`touchstart` (часть вебвью не даёт автоплей до касания).
- Пауза по `visibilitychange` и при размонтировании — иначе видео жжёт батарею впустую.
- `prefers-reduced-motion: reduce` → принудительно `wash`, canvas не запускается.
- Глобальный тумблер «живой фон» в разделе «Моё», состояние в `localStorage`. Выключенный →
  `wash` везде.
- Canvas-пыль: тёплые частицы, всплывающие вверх с боковым дрейфом, ~20% из них — размытые боке.
  Плотность считается от площади холста, пересчёт по `ResizeObserver`. Стоит ~3 КБ против 439 КБ
  видео, поэтому и стоит на длинных списках.

Интенсивность фона на витрине — 100%, как выбрано на прототипе.

## 7. Порядок работ

1. **Фундамент.** Токены, шрифты в бандле, чистка инлайн-стилей. Визуально почти ничего не
   меняется — это подготовка почвы.
2. **Фуллскрин и инсеты.** `lib/telegram.js`, хедер, нижняя навигация, скрим.
3. **Тема Studio.** Компоненты, затем экраны.
4. **Фон.** `AmbientBackground`, ролик в `public/bg/`, тумблер в «Моё».
5. **Документация.** §13 внешнего `BAZA_CONTEXT.md`.

Порядок важен: без шага 1 каждый следующий превращается в правку двадцати файлов, без шага 2
тема будет свёрстана под неверные отступы.

## 8. Проверка

Автотестов у фронтенда нет — в проекте есть только `backend/tests` на pytest. Проверка ручная,
и это надо принимать как факт, а не делать вид, что есть покрытие.

Обязательный чек-лист перед деплоем:

- [ ] Фуллскрин включается на iPhone с Dynamic Island, с чёлкой и на Android
- [ ] На клиенте старше Bot API 8.0 приложение выглядит корректно в обычном режиме
- [ ] Заголовок не залезает под вырез, кнопки Telegram не перекрывают элементы приложения
- [ ] «Моё» в нижней навигации не перехватывается системным жестом
- [ ] Свайп вниз по статье не закрывает приложение
- [ ] Видео стартует само; если нет — стартует после первого касания
- [ ] Луп без рывка на стыке
- [ ] Фон не пожирает батарею: пауза при сворачивании проверена
- [ ] `prefers-reduced-motion` отключает и видео, и canvas
- [ ] Гейт-флоу цел: `POST /api/gate/check` вручную, экран гейта и переход после подписки
- [ ] Работает локально через `docker compose up`
- [ ] Вес бандла: до / после, видео учтено отдельно
